# Business Modules — RBMS-POS

> เอกสารวิเคราะห์ Business Logic + Workflow ของแต่ละ Module ในระบบ RBMS-POS
> สำหรับใช้อ้างอิงในการเขียนรายงาน — เน้นมุมมองธุรกิจร้านอาหาร (ไม่ลงรายละเอียดเทคนิค)

---

## โครงสร้างเอกสาร

ในแต่ละไฟล์ Module จะมี:

1. **Module นี้คืออะไร** — สรุป 1-2 ประโยค
2. **ช่วยธุรกิจร้านอาหารในเรื่องใด** — ปัญหาที่แก้ + คุณค่าทางธุรกิจ
3. **Business Logic หลัก** — กฎเกณฑ์ของระบบ
4. **Workflow การทำงานจริง** — ลำดับขั้นตอนใช้งานในร้าน
5. **ข้อดี (Pros)** — จุดเด่นเมื่อเทียบกับวิธีดั้งเดิม
6. **ข้อเสีย / ข้อจำกัด (Cons)** — สิ่งที่ต้องระวัง
7. **ความสัมพันธ์กับ Module อื่น** — ใช้ข้อมูลจากใคร / ใครเอาข้อมูลเราไปใช้

---

## ลำดับการอ่าน + เหตุผล

แนะนำให้อ่านตามลำดับนี้ เพราะ module หลังขึ้นอยู่กับ module ก่อนหน้า:

| ลำดับ | Module | สรุปสั้น | ทำไมต้องอ่านก่อน |
| :---: | --- | --- | --- |
| 1 | [Authorization](01-authorization.md) | กำหนดสิทธิ์การเข้าถึงตามตำแหน่งงาน (RBAC) | ทุก Module ต้องตรวจสิทธิ์ก่อนทำงาน |
| 2 | [Admin](02-admin.md) | ล็อกอิน + ตั้งค่าร้าน + ค่าบริการ + ผู้ใช้งาน + รอบขาย + แดชบอร์ด | บริการพื้นฐานที่ทุก module ใช้ |
| 3 | [Human Resource](03-human-resource.md) | จัดการข้อมูลพนักงาน + ผูกบัญชีผู้ใช้ | พนักงานเป็นคนใช้งานระบบ + ทุก audit อ้างพนักงาน |
| 4 | [Menu](04-menu.md) | จัดการเมนูอาหาร + หมวดหมู่ + ตัวเลือกเสริม | ออเดอร์ดึงเมนูจาก Module นี้ |
| 5 | [Table](05-table.md) | จัดการโต๊ะ + ผังร้าน + การจองโต๊ะ | ออเดอร์ผูกกับโต๊ะ + QR Code อยู่ที่นี่ |
| 6 | [Order](06-order.md) | รับออเดอร์ + ส่งครัว + เสิร์ฟ + แยกบิล + Self-Order | หัวใจของระบบ POS |
| 7 | [Payment](07-payment.md) | ชำระเงินสด/QR + ใบเสร็จ + ตรวจสลิปด้วย OCR | ปิดวงจรการขาย |
| 8 | [Notification](08-notification.md) | แจ้งเตือนพนักงาน Real-time ผ่าน SignalR | ข้อมูลเรียลไทม์ตลอดทั้งระบบ |

## วิธีนำไปใช้เขียนรายงาน

แต่ละไฟล์ออกแบบให้คัดลอกหัวข้อไปใช้ในรายงานได้โดยตรง โดย:

- **บทที่ 3-4 (การออกแบบระบบ + Business Logic)** → ใช้หัวข้อ Business Logic + Workflow
- **บทที่ 5 (ประโยชน์ + ผลที่ได้รับ)** → ใช้หัวข้อ "ช่วยธุรกิจในเรื่องใด" + "ข้อดี"
- **บทที่ 6 (ข้อจำกัด + ข้อเสนอแนะ)** → ใช้หัวข้อ "ข้อเสีย / ข้อจำกัด"
- **บทที่ 7 (สถาปัตยกรรม)** → ใช้แผนผังความสัมพันธ์ระหว่าง Module
