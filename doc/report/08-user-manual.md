# คู่มือการใช้งานระบบ

> เนื้อหาพร้อมใช้ — แบ่งตามหลัก Use Case 3 บทบาทพื้นฐาน (Admin / Staff / Customer)
> โดยส่วน Staff แบ่งย่อยตามหน้าที่ในร้าน เพื่อให้ครอบคลุมตำแหน่งที่หลากหลายของแต่ละร้าน
> รูปประกอบ ผู้จัดทำดูได้จากบทที่ 4 ผลการดำเนินงาน

---

คู่มือการใช้งานระบบบริหารธุรกิจร้านอาหารผ่านเว็บพร้อมระบบ POS ฉบับนี้ จัดทำขึ้นเพื่ออธิบายขั้นตอนการใช้งานระบบแบบอ้างอิงลำดับขั้นตอน (Step-by-Step) ตามหลัก Use Case ของระบบที่แบ่งผู้ใช้งานออกเป็น 3 กลุ่มพื้นฐาน ได้แก่ ผู้ดูแลระบบ (Admin) พนักงาน (Staff) ซึ่งสามารถแบ่งย่อยเป็นหน้าที่ในร้าน เช่น พนักงานเสริฟ พนักงานครัว แคชเชียร์ และลูกค้า (Customer) ที่ใช้ระบบ Self-Order โดยผู้ใช้งานสามารถดูภาพประกอบการทำงานของแต่ละหน้าจอได้ใน บทที่ 4 ผลการดำเนินงาน

---

## ส่วนที่ 1: คู่มือสำหรับผู้ดูแลระบบ (Admin)

ผู้ดูแลระบบมีหน้าที่ในการตั้งค่าระบบ จัดการข้อมูลพื้นฐานของร้าน และเรียกดูรายงานยอดขาย โดยมีขั้นตอนการใช้งานดังนี้

### 1. การเข้าสู่ระบบ

- เข้าสู่หน้าแรกของระบบ Admin Client
- กรอก Username และ Password ของบัญชีผู้ดูแลระบบ
- ระบบจะตรวจสอบสิทธิ์ผ่าน JWT และนำผู้ใช้งานเข้าสู่หน้า Dashboard

### 2. การจัดการเมนูอาหาร

- ไปที่เมนู "จัดการเมนู"
- เพิ่มหมวดหมู่ใหม่ โดยระบุชื่อหมวด และประเภท (อาหาร / เครื่องดื่ม / ของหวาน)
- เพิ่มเมนูใหม่ โดยกรอกชื่อเมนู ราคา หมวดหมู่ และอัปโหลดรูปภาพ
- สร้างกลุ่มตัวเลือกเสริม (Option Group) และเพิ่ม Option ย่อยพร้อมราคาเสริม
- ผูก Option Group กับเมนูที่ต้องการ
- ปักหมุดเมนูแนะนำ หรือปิดการขายชั่วคราวได้ที่ปุ่มข้างเมนูแต่ละรายการ

### 3. การจัดการตำแหน่งงานและสิทธิ์ (Permission Matrix)

- ไปที่เมนู "ตำแหน่งงาน"
- สร้างตำแหน่งใหม่ตามโครงสร้างของร้าน
- เปิดหน้า Permission Matrix และติ๊กเลือกสิทธิ์ของแต่ละ Module (read / create / update / delete)
- บันทึกการตั้งค่า

**หมายเหตุสำคัญ**: การเปลี่ยนแปลง Permission จะมีผลทันทีกับผู้ใช้ในตำแหน่งนั้น เมื่อเข้าสู่ระบบครั้งถัดไป

### 4. การจัดการพนักงาน

- ไปที่เมนู "พนักงาน"
- เพิ่มพนักงานใหม่ พร้อมกรอกข้อมูลส่วนตัว ที่อยู่ ประวัติการศึกษา และประวัติการทำงาน
- อัปโหลดรูปประจำตัวพนักงาน
- ผูกพนักงานกับตำแหน่งงานที่กำหนด
- สร้างบัญชี User (Username + Password) ให้พนักงานเพื่อเข้าสู่ระบบ

### 5. การจัดการโต๊ะและผังร้าน

- ไปที่เมนู "ผังร้าน"
- สร้างโซน (Zone) ตามพื้นที่ของร้าน เช่น โซนชั้น 1 โซนชั้น 2
- เพิ่มโต๊ะในแต่ละโซน พร้อมระบุจำนวนที่นั่ง
- เพิ่ม Floor Object เช่น ห้องน้ำ บันได เคาน์เตอร์ ครัว ทางออก
- ใช้ฟังก์ชัน Drag-and-Drop เพื่อจัดวางตำแหน่งโต๊ะและ Object บนผังร้านให้สอดคล้องกับร้านจริง

### 6. การตั้งค่าค่าบริการและข้อมูลร้าน

- ไปที่เมนู "ตั้งค่า"
- กำหนดอัตราค่าบริการ (Service Charge) เป็นเปอร์เซ็นต์หรือจำนวนเงิน พร้อมระบุช่วงวันที่ที่ใช้งาน
- ตั้งค่าข้อมูลร้าน เช่น ชื่อร้าน โลโก้ เวลาเปิด-ปิด

### 7. การดู Dashboard และรายงาน

- ไปที่เมนู "Dashboard"
- ดูยอดขายในช่วงเวลาที่เลือก
- ดูเมนูขายดีและรายงานสรุป

### 8. การสร้าง QR Code สำหรับ Self-Order

- ไปที่เมนู "QR Code"
- สร้าง QR Code สำหรับแต่ละโต๊ะ
- ดาวน์โหลดหรือพิมพ์ QR Code เพื่อนำไปติดบนโต๊ะ

**หมายเหตุสำคัญ**: QR Code มี Token อายุ 12 ชั่วโมง หลังจากนั้นต้องสร้างใหม่หรือใช้ระบบ Auto-Regenerate ของระบบ

## ส่วนที่ 2: คู่มือสำหรับพนักงาน (Staff)

พนักงานเป็นผู้ที่ปฏิบัติงานในร้านในหน้าที่ต่าง ๆ ซึ่งสิทธิ์การเข้าถึงเมนูจะแตกต่างกันตามตำแหน่งงานที่ผู้ดูแลระบบกำหนดให้ ในคู่มือฉบับนี้จะแบ่งหน้าที่หลัก 3 ส่วน ได้แก่ การรับออเดอร์และจัดการโต๊ะ การจัดการในครัว และการรับชำระเงิน

### ส่วนที่ 2.1: การรับออเดอร์และจัดการโต๊ะ

#### 1. การเข้าสู่ระบบ

- เข้าสู่ระบบด้วยบัญชีพนักงาน ระบบจะนำไปยังหน้าหลักตามสิทธิ์ที่ได้รับ

#### 2. การรับ Order ที่โต๊ะ

- ไปที่เมนู "ภาพรวมร้าน" หรือ "ผังร้าน"
- เลือกโต๊ะที่มีสถานะ Available
- กดปุ่ม "สั่งอาหาร" และเลือกเมนูที่ลูกค้าต้องการ
- ระบุ Option Group ตามที่ลูกค้าต้องการ (เช่น เผ็ดน้อย เพิ่มไข่)
- กดปุ่ม "ส่งครัว" เพื่อส่งรายการอาหารไปยังครัวผ่าน SignalR

#### 3. การจัดการสถานะโต๊ะ

- คลิกที่โต๊ะ → เลือกการเปลี่ยนสถานะ
- สถานะที่รองรับ ได้แก่ Available, Reserved, Occupied, Billing, Cleaning, Unavailable

#### 4. การจองโต๊ะ (Reservation)

- ไปที่เมนู "จองโต๊ะ"
- ระบุชื่อลูกค้า เบอร์โทรศัพท์ วันที่และเวลาที่จอง พร้อมเลือกโต๊ะ
- ระบบจะเปลี่ยนสถานะโต๊ะเป็น Reserved ตามช่วงเวลาที่จอง

#### 5. การผูกโต๊ะ (Table Link)

- เลือกโต๊ะหลัก → กดปุ่ม "ผูกโต๊ะ"
- เลือกโต๊ะที่ต้องการรวม
- ระบบจะรวมออเดอร์ของโต๊ะเหล่านั้นเข้าด้วยกัน เหมาะสำหรับลูกค้ากลุ่มใหญ่

#### 6. การ Served รายการอาหาร

- เมื่อครัวเปลี่ยนสถานะเป็น Ready ระบบจะแจ้งเตือนผ่าน Toast
- พนักงานเสริฟอาหารและกดปุ่ม "Served" เพื่อเปลี่ยนสถานะรายการเป็น Served

### ส่วนที่ 2.2: การจัดการในครัว (Kitchen Display)

#### 1. การเปิด Kitchen Display

- เข้าสู่ระบบด้วยบัญชีพนักงานครัว
- หน้าจอแสดงรายการอาหารทั้งหมดที่อยู่ในสถานะ Sent หรือ Preparing

#### 2. การกรองรายการตามหมวด

- เลือก Tab Food / Beverage / Dessert เพื่อแสดงเฉพาะหมวดที่ต้องการ

#### 3. การเริ่มทำอาหาร

- คลิกที่รายการอาหารที่ต้องการเริ่มทำ
- กดปุ่ม "เริ่มทำ" สถานะจะเปลี่ยนจาก Sent เป็น Preparing

#### 4. การแจ้งอาหารพร้อม

- เมื่อทำอาหารเสร็จ กดปุ่ม "เสร็จแล้ว" สถานะจะเปลี่ยนเป็น Ready
- ระบบจะแจ้งเตือนพนักงานหน้าร้านผ่าน SignalR Toast ทันที

#### 5. การยกเลิกรายการ (Void)

- กรณีลูกค้าขอยกเลิก พนักงานครัวกดปุ่ม "Void"
- ระบุเหตุผลในการยกเลิก
- ระบบจะเปลี่ยนสถานะเป็น Voided

**หมายเหตุสำคัญ**: ระบบอนุญาตให้ Void รายการที่อยู่ในสถานะ Sent หรือ Preparing เท่านั้น รายการที่อยู่ในสถานะ Ready หรือ Served จะไม่สามารถ Void ได้

### ส่วนที่ 2.3: การรับชำระเงิน (Cashier)

#### 1. การเปิด Cashier Session

- เข้าสู่ระบบด้วยบัญชีแคชเชียร์
- ไปที่เมนู "Cashier Session"
- กดปุ่ม "เปิดกะ" และระบุยอดเงินสดเริ่มต้นในลิ้นชัก

#### 2. การรับชำระเงินสด

- เลือก Order ที่อยู่ในสถานะ Billing
- กดปุ่ม "ชำระเงิน" → เลือก "Cash"
- ระบุจำนวนเงินที่ลูกค้าจ่าย ระบบจะคำนวณเงินทอนอัตโนมัติ
- กดยืนยันการชำระ

#### 3. การรับชำระเงินผ่าน QR Code พร้อม OCR

- เลือก Order → เลือก "QR Payment"
- ระบบสร้าง QR Code สำหรับลูกค้าสแกน
- เมื่อลูกค้าโอนเงินเสร็จ อัปโหลดรูปสลิปโอนเข้าระบบ
- ระบบ OCR จะอ่านยอดเงินจากสลิปและเปรียบเทียบกับยอดที่ต้องชำระ
- หากตรงกัน ระบบแสดงสถานะ Matched และยืนยันได้ทันที
- หากไม่ตรง ระบบแสดงสถานะ Mismatched ให้แคชเชียร์ตรวจสอบ
- หาก OCR อ่านสลิปไม่ชัดเจน ระบบแสดงสถานะ Manual ให้แคชเชียร์ตรวจมือเอง

**หมายเหตุสำคัญ**: ระบบจะบันทึกประวัติการตรวจสลิปทุกครั้ง รวมถึงรูปสลิปที่อัปโหลด เพื่อใช้ตรวจสอบย้อนหลังได้

#### 4. การแยกบิล (Split Bill)

- ในหน้า Order ที่สถานะ Billing → กดปุ่ม "Split Bill"
- เลือกรูปแบบการแยก ได้แก่ "แยกตามรายการ" หรือ "แยกตามจำนวนเงิน"
- ระบบจะสร้างบิลย่อยตามจำนวนที่ระบุ

**หมายเหตุสำคัญ**: การ Unsplit (รวมบิลกลับ) สามารถทำได้เฉพาะกรณีที่ยังไม่มีบิลใดถูกชำระเงิน หากมีบิลใดที่ Paid แล้ว จะไม่สามารถ Unsplit ได้

#### 5. การพิมพ์ใบเสร็จ

- หลังจากชำระเงินสำเร็จ ระบบจะแสดงหน้าใบเสร็จ
- กดปุ่ม "พิมพ์ใบเสร็จ"

#### 6. การปิด Cashier Session

- เมื่อสิ้นกะ กลับไปที่เมนู "Cashier Session"
- กดปุ่ม "ปิดกะ" และระบุยอดเงินสดในลิ้นชักจริง
- ระบบจะเปรียบเทียบยอดที่ระบบบันทึก (Expected Cash) กับยอดจริง (Final Cash) พร้อมแสดงผลต่าง (Difference)
- หากยอดตรงกัน Session จะถูกปิดสมบูรณ์

## ส่วนที่ 3: คู่มือสำหรับลูกค้า (Customer Self-Order)

ลูกค้าสามารถสั่งอาหารได้ด้วยตนเองผ่าน QR Code ที่ติดอยู่บนโต๊ะ โดยมีขั้นตอนดังนี้

### 1. การสแกน QR Code ที่โต๊ะ

- เปิดแอป Camera หรือ QR Scanner บนมือถือ
- สแกน QR Code ที่ติดอยู่บนโต๊ะ
- ระบบจะเปิด Mobile Web ของระบบโดยอัตโนมัติ

**หมายเหตุสำคัญ**: QR Code มี Token อายุ 12 ชั่วโมง หากเกินกำหนดต้องสแกนใหม่หรือขอความช่วยเหลือจากพนักงาน

### 2. การเลือกเมนูและสั่งอาหาร

- ดู Browse เมนูพร้อมรูปภาพและราคา
- เลือกเมนูที่ต้องการ
- เลือก Option Group ตามต้องการ (เช่น ระดับความหวาน เพิ่มท็อปปิ้ง)
- กดปุ่ม "เพิ่มลงตะกร้า"

### 3. การดูตะกร้าและยืนยันการสั่ง

- ไปที่หน้าตะกร้า
- ตรวจสอบรายการและยอดรวม
- กดปุ่ม "ยืนยันการสั่ง"

**หมายเหตุสำคัญ**: หากเปิด QR Code จากหลายเครื่องในโต๊ะเดียวกัน ระบบจะอนุญาตให้สั่งจากเครื่องที่ Claim Token ก่อนเท่านั้น (Bill Claim Token) เพื่อป้องกันการสั่งซ้ำซ้อน

### 4. การติดตามสถานะอาหารแบบ Real-time

- ไปที่หน้า "Order ของฉัน"
- ระบบแสดงสถานะอาหารแต่ละรายการ (Pending / Sent / Preparing / Ready / Served) แบบ Real-time

### 5. การเรียกพนักงาน

- ที่หน้าหลัก กดปุ่ม "เรียกพนักงาน"
- พนักงานหน้าร้านจะได้รับการแจ้งเตือนผ่าน SignalR Toast ทันที

### 6. การขอชำระเงิน

- กดปุ่ม "ขอชำระเงิน"
- ระบบจะแจ้งเตือนแคชเชียร์
- แคชเชียร์จะมาเก็บเงินที่โต๊ะหรือลูกค้าเดินไปจ่ายที่เคาน์เตอร์

---

## หมายเหตุทั่วไป

- ระบบรองรับการใช้งานบน Browser สมัยใหม่ทั้งบน Desktop และ Mobile
- การใช้งานต้องเชื่อมต่อกับเครือข่าย Wi-Fi ที่เสถียรเพื่อรองรับการสื่อสารแบบ Real-time ผ่าน SignalR
- ระบบจัดเก็บประวัติการทำงานของทุก User สำหรับการตรวจสอบย้อนหลัง
- หากพบปัญหาในการใช้งาน กรุณาติดต่อผู้ดูแลระบบของร้าน
