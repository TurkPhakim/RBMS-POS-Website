# ผลการทดสอบระบบ RBMS-POS — แยกตามโมดูล

> วิเคราะห์จากโค้ดจริง (Backend Controllers + Services + Frontend Components)
> รูปแบบ: ความคาดหวัง → ลำดับฟีเจอร์/Flow → ผลทดสอบ (ทำได้ / ทำไม่ได้)

---

## 1. Auth Module (เข้าสู่ระบบ)

**ความคาดหวัง:** ผู้ใช้สามารถเข้าสู่ระบบ ออกจากระบบ กู้คืนรหัสผ่าน และมีระบบความปลอดภัยป้องกันการเข้าถึงที่ไม่ได้รับอนุญาต

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | Login ด้วย Username + Password + ReCaptcha | ✅ ทำได้ |
| 2 | Logout + เพิกถอน Token | ✅ ทำได้ |
| 3 | Auto Refresh Token เมื่อ Access Token หมดอายุ | ✅ ทำได้ |
| 4 | ล็อคบัญชีอัตโนมัติหลังกรอกรหัสผิด 3 ครั้ง (Exponential lockout: 1,3,5,7 นาที) | ✅ ทำได้ |
| 5 | Admin ล็อค/ปลดล็อคบัญชีผู้ใช้ + ตั้งวันปลดล็อคอัตโนมัติ | ✅ ทำได้ |
| 6 | ลืมรหัสผ่าน → กรอก Email → ระบบส่ง OTP 6 หลัก (หมดอายุ 3 นาที) | ✅ ทำได้ |
| 7 | ยืนยัน OTP (จำกัด 5 ครั้ง) → ได้รับ Reset Token | ✅ ทำได้ |
| 8 | ตั้งรหัสผ่านใหม่ + ตรวจสอบไม่ให้ซ้ำ 3 รหัสล่าสุด (Password History) | ✅ ทำได้ |
| 9 | เปลี่ยนรหัสผ่าน (ต้องยืนยันรหัสเก่าก่อน) | ✅ ทำได้ |
| 10 | ReCaptcha ป้องกัน Bot | ✅ ทำได้ |
| 11 | ยืนยันรหัสผ่าน (Credential Check) สำหรับ action สำคัญ | ✅ ทำได้ |

**WorkFlow — เข้าสู่ระบบ:**
| ขั้นตอน | ผล |
|--------|-----|
| กรอก Username + Password + Captcha → ตรวจสอบ → เข้าสู่ Dashboard | ✅ ทำได้ |
| กรอกผิด → แสดงจำนวนครั้งที่เหลือ → ล็อคอัตโนมัติ | ✅ ทำได้ |

**WorkFlow — ลืมรหัสผ่าน:**
| ขั้นตอน | ผล |
|--------|-----|
| กรอก Email → รับ OTP → ยืนยัน OTP → ตั้งรหัสใหม่ → Login | ✅ ทำได้ |

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | ดูข้อมูลส่วนตัว (ชื่อ, เพศ, วันเกิด, อายุคำนวณอัตโนมัติ, สัญชาติ, ศาสนา) | ✅ ทำได้ |
| 2 | แก้ไขข้อมูลที่อนุญาต (ชื่อเล่น, Line ID, เบอร์โทร, ธนาคาร, เลขบัญชี) | ✅ ทำได้ |
| 3 | อัพโหลด/ลบรูปโปรไฟล์ | ✅ ทำได้ |
| 4 | เพิ่ม/แก้ไข/ลบที่อยู่ (หลายรายการ) | ✅ ทำได้ |
| 5 | เพิ่ม/แก้ไข/ลบประวัติการศึกษา | ✅ ทำได้ |
| 6 | เพิ่ม/แก้ไข/ลบประวัติงาน | ✅ ทำได้ |
| 7 | ตั้งค่า PIN 6 หลัก (ยืนยันรหัสผ่านก่อน) | ✅ ทำได้ |
| 8 | เปลี่ยน PIN (กรอก PIN เก่า → ตั้ง PIN ใหม่) | ✅ ทำได้ |
| 9 | รีเซ็ต PIN ด้วยรหัสผ่าน (กรณีลืม PIN) | ✅ ทำได้ |

**WorkFlow — แก้ไขโปรไฟล์:**

|--------|-----|
| กดปุ่ม "ตั้งค่า PIN" → ยืนยันรหัสผ่าน → กรอก PIN ใหม่ → ยืนยัน PIN → สำเร็จ | ✅ ทำได้ |
