> ผู้จัดทำกรอกเลขหน้าจริงเมื่อ Export เป็น Word/PDF

## ⚠️ Remark — หลักการตั้งชื่อรูป (สำหรับใช้ตอนเพิ่มรูปประกอบจริง)

ตั้งชื่อรูปให้ **เหมาะสม + ไม่ซ้ำซ้อน + ไม่ยาวเกิน** โดยใช้หลักดังนี้

### หลัก 5 ข้อ

1. **สั้น กระชับ ไม่เกิน 8-12 คำ** — ถ้าคำอธิบายซับซ้อนเกิน ให้แยกเป็นรูปย่อย (เช่น "รูปที่ 4.7", "รูปที่ 4.7 (ต่อ)")
2. **ขึ้นต้นด้วยคำที่ระบุประเภท** — "หน้าจอแสดง...", "แผนภาพ...", "สัญลักษณ์...", "ตาราง..."
3. **ระบุสิ่งที่อยู่ในภาพ ไม่ใช่การกระทำ** — เช่น "หน้าจอจัดการเมนู" ไม่ใช่ "ขั้นตอนการกดปุ่ม"
4. **ห้ามใช้คำซ้ำกันในรูปต่าง ๆ** — ถ้ามีหลายหน้าจอที่คล้ายกัน ให้ระบุข้อแตกต่าง
5. **ใช้สำนวนเดียวกันตลอดบท** — ถ้าใช้ "หน้าจอแสดง..." ก็ใช้ตลอด ไม่สลับเป็น "หน้าจอของ..." หรือ "หน้าจอที่..."
