## สิ่งที่ต้องเตรียมก่อนกรอกเนื้อหา

1. **กำหนดเดือนเริ่ม-จบโครงงาน** (สำหรับ 1.5 และ Gantt Chart)
2. **เตรียม Screenshot ระบบจริง** ~100-200 รูป (สำหรับบทที่ 4)
3. **สร้าง Flowchart 10 รูป** (สำหรับ 3.2.1-3.2.10) — แนะนำใช้ draw.io
4. **สร้าง ER Diagram 5 รูป** (สำหรับ 3.4) — รวม 1 + แยกตาม domain 4 รูป
5. **รวบรวม Logo + URL ที่มา** ของแต่ละ Tech Stack 14 ตัว (สำหรับบทที่ 2)
6. **ตรวจสอบรูปแบบ Citation Style** กับอาจารย์ที่ปรึกษา (ค่าเริ่มต้นใน 04 ใช้ IEEE Style)
7. **กรอกข้อมูลส่วนตัว** ของผู้จัดทำในไฟล์ 01 (ชื่อ-นามสกุล รหัสนักศึกษา อาจารย์ที่ปรึกษา ปีการศึกษา)
