# ผลการทดสอบระบบ RBMS-POS — แยกตามโมดูล

> วิเคราะห์จากโค้ดจริง (Backend + Frontend) — ทดสอบทุกฟีเจอร์ตาม Flow การใช้งานจริง

---

## 1. Auth Module (เข้าสู่ระบบ)

**ความคาดหวัง:** ผู้ใช้เข้าสู่ระบบ กู้คืนรหัสผ่าน และมีระบบความปลอดภัยครบ

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | Login (Username + Password + ReCaptcha) + Logout + Auto Refresh Token | ✅ |
| 2 | ล็อคบัญชีอัตโนมัติหลังกรอกรหัสผิด (Exponential lockout) + Admin ล็อค/ปลดล็อค | ✅ |
| 3 | ลืมรหัสผ่าน → ส่ง OTP ทาง Email → ยืนยัน → ตั้งรหัสใหม่ (ห้ามซ้ำ 3 รหัสล่าสุด) | ✅ |
| 4 | เปลี่ยนรหัสผ่าน + ยืนยันรหัสสำหรับ action สำคัญ | ✅ |

---

## 2. Profile Module (โปรไฟล์)

**ความคาดหวัง:** พนักงานดู/แก้ไขข้อมูลส่วนตัว จัดการข้อมูลเพิ่มเติม และตั้งค่า PIN

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | ดูข้อมูลส่วนตัว + แก้ไขข้อมูลที่อนุญาต (ชื่อเล่น, Line, เบอร์, ธนาคาร) | ✅ |
| 2 | อัพโหลด/ลบรูปโปรไฟล์ | ✅ |
| 3 | จัดการที่อยู่ / ประวัติการศึกษา / ประวัติงาน (CRUD หลายรายการ) | ✅ |
| 4 | ตั้งค่า / เปลี่ยน / รีเซ็ต PIN 6 หลัก | ✅ |

---

## 3. Dashboard Module (แดชบอร์ด)

**ความคาดหวัง:** แสดงภาพรวมร้านด้วย KPI, กราฟ, สถิติ

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | KPI Cards 6 ใบ (ยอดขาย, ออเดอร์, ลูกค้า, เฉลี่ย/ออเดอร์, กำไร, %กำไร) | ✅ |
| 2 | กราฟ 4 แบบ (แนวโน้มรายได้, เปรียบเทียบช่วงเวลา, สัดส่วนครัว, ชั่วโมงขายดี) | ✅ |
| 3 | Top 5 เมนูขายดี (แยก อาหาร/เครื่องดื่ม/ของหวาน) | ✅ |
| 4 | รายงานยอดขายตามช่วงวันที่ + เลือกวันที่กรอง + สลับ 7/30 วัน | ✅ |

## 4. Order Module (ออเดอร์)

**ความคาดหวัง:** จัดการออเดอร์ครบวงจร ตั้งแต่เปิดโต๊ะจนถึงขอบิล

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | ดูภาพรวมร้าน (ผังโต๊ะ Real-time) + รายการออเดอร์ (Pagination + Filter) | ✅ |
| 2 | สร้าง Order + เพิ่มรายการอาหาร (เมนู + ตัวเลือก + จำนวน) + ส่งครัว Real-time | ✅ |
| 3 | Status Flow: Pending → Cooking → Ready → Served → Completed | ✅ |
| 4 | Void / Cancel รายการ (พร้อมเหตุผล) | ✅ |
| 5 | ขอบิล + ส่ง/ยกเลิกบิล + แยกบิล (ตามรายการ / ตามจำนวนเงิน) + ยกเลิกแยก | ✅ |
| 6 | รวมโต๊ะ + ย้ายโต๊ะ (โอนข้อมูล + สร้าง QR ใหม่ + แจ้งเตือน) | ✅ |

## 5. Menu Module (เมนู)

**ความคาดหวัง:** จัดการเมนูอาหาร เครื่องดื่ม ของหวาน รวมถึงหมวดหมู่และตัวเลือกเสริม

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | ดูรายการเมนู แยกประเภท + ค้นหา + กรองสถานะ (Permission แยกแต่ละประเภท) | ✅ |
| 2 | CRUD เมนู (ชื่อ, ราคา, ต้นทุน, หมวดหมู่, รูปภาพ, ตัวเลือกเสริม) | ✅ |
| 3 | จัดการหมวดหมู่ย่อย CRUD + จัดเรียง Drag & Drop | ✅ |
| 4 | จัดการกลุ่มตัวเลือก + รายการตัวเลือก CRUD + เชื่อมกับเมนู | ✅ |

**ความคาดหวัง:** จัดการโซน โต๊ะ ออกแบบผังร้าน และจัดการการจอง

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|

| 2 | จัดการโต๊ะ CRUD + สถานะ + เปิด/ปิด + QR Token + รวม/แยกโต๊ะ | ✅ |
| 3 | ออกแบบผังร้าน Drag & Drop (โต๊ะ + วัตถุตกแต่ง) | ✅ |

## 7. Payment Module (ชำระเงิน)

**ความคาดหวัง:** จัดการรอบขาย ชำระเงินทั้งเงินสดและ QR ตรวจสลิปอัตโนมัติ ออกใบเสร็จ

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | เปิด/ปิดรอบขาย + เงินเข้า/ออกลิ้นชัก + สรุปยอด | ✅ |
| 2 | ชำระเงินสด (คำนวณทอนอัตโนมัติ) | ✅ |
| 3 | ชำระ QR + อัพโหลดสลิป + Slip OCR ตรวจอัตโนมัติ + แคชเชียร์ยืนยัน | ⚠️ |

> **⚠️ ข้อจำกัด Slip OCR**: ระบบตรวจสลิปอัตโนมัติทำงานได้กับสลิปที่เป็น screenshot จากแอปธนาคาร แต่ **ไม่สามารถตรวจสลิปที่ถ่ายจากหน้าจอมือถือ (ภาพถ่าย) ได้** เนื่องจากคุณภาพภาพ, มุมเอียง, แสงสะท้อน ทำให้ OCR อ่านข้อมูลผิดพลาด — กรณีนี้แคชเชียร์ต้องตรวจสอบและยืนยันด้วยตนเอง
| 4 | ประวัติชำระเงิน + ประวัติรอบขาย + รายละเอียดรอบขาย | ✅ |
| 5 | ออกใบเสร็จ / ดาวน์โหลด (รายบิล + รวม) | ✅ |

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | แสดงรายการรอทำ แยกประเภท (อาหาร/เครื่องดื่ม/ของหวาน) + 2 มุมมอง (Order/Menu View) | ✅ |
| 2 | อัพเดตสถานะ: เริ่มทำ → ทำเสร็จ + Real-time ทั้งรับและส่ง (SignalR) | ✅ |
| 3 | แสดงข้อมูลโต๊ะ/โซน + KPI สรุป + Permission แยกตาม category | ✅ |

**ความคาดหวัง:** จัดการผู้ใช้ ตำแหน่ง สิทธิ์การเข้าถึง ตั้งค่าร้าน และค่าบริการ

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | จัดการผู้ใช้งาน (ดู + แก้สถานะ + ล็อค/ปลดล็อค + รีเซ็ต Failed Login) | ✅ |
| 2 | จัดการตำแหน่ง CRUD + Permission Matrix (Tree + Checkbox) + Module Tree | ✅ |
| 3 | ตั้งค่าร้านค้า (ข้อมูลร้าน + โลโก้ + QR ชำระเงิน + เวลาเปิด-ปิด) | ✅ |
| 4 | จัดการค่าบริการ CRUD (ชื่อ, เปอร์เซ็นต์, สถานะ) | ✅ |

## 11. Mobile Web (ลูกค้าสั่งอาหารเอง)

**ความคาดหวัง:** ลูกค้าสแกน QR → ดูเมนู → สั่งอาหาร → ติดตามสถานะ → ชำระเงิน → รับใบเสร็จ

| # | ฟีเจอร์ / Flow | ผล |
|---|---------------|-----|
| 1 | สแกน QR ที่โต๊ะ → Session Token + ตั้งชื่อเล่น | ✅ |
| 2 | เรียกดูเมนูแยกหมวด + ค้นหา + ดูรายละเอียด + เลือกตัวเลือกเสริม | ✅ |
| 3 | ตะกร้า (เพิ่ม/แก้ไข/ลบ) + สั่งอาหาร → ส่งครัว | ✅ |
| 4 | ติดตามสถานะ Real-time + เรียกพนักงาน (Cooldown 60 วิ) | ✅ |
| 5 | ขอบิล + รอบิล (auto-navigate) + ดูสรุปบิล | ✅ |
| 6 | ชำระเงินสด / QR + อัพโหลด Slip + หารบิลเท่า / หารตามรายการ | ✅ |
| 7 | รอตรวจ Slip → ชำระสำเร็จ → ดาวน์โหลดใบเสร็จ | ✅ |
| 8 | หน้าร้านปิด + หน้า Token หมดอายุ | ✅ |
