## แนวคิดร้าน

| รายละเอียด | คำอธิบาย |
|-----------|---------|
| **ธีม** | ร้านอาหารนานาชาติ (International Cuisine) |
| **ช่วงเช้า (Period 1)** | คาเฟ่ — Brunch, กาแฟ, ชา, เพสตรี้, ของหวาน |
| **ช่วงเย็น (Period 2)** | ร้านอาหาร + บาร์ — อาหารนานาชาติ, ค็อกเทล, ไวน์, เบียร์ |
| **ทั้งสองช่วง** | สลัด, ซุป, สมูทตี้, ม็อกเทล, ของหวานบางรายการ |

### สัญลักษณ์

- **P1** = ขายช่วงเช้า (IsAvailablePeriod1)
- **P2** = ขายช่วงเย็น (IsAvailablePeriod2)
- **P1+P2** = ขายทั้งสองช่วง
- ⭐ = Recommended (Tags)
- 🕐 = SlowPreparation (Tags)

| รหัส | สารก่อภูมิแพ้ | ตัวอย่างแหล่งที่มา |
